## 判定範囲と根拠

OP・ED・劇中歌、CM、イベントのテーマ、公式が命名したアーティストタイアップ企画を含む。通常のゲーム収録、一般の実写ライブ演奏、単なるMV公開、作曲者の参加だけでは判定していない。公式にキャラクターソングとして発表されたものは、その用途を記載する。

公式の楽曲別説明、アニメ・映画・放送局の主題歌表、監修された公式曲集、主催者・運営会社の発表を優先。一部は専門誌・楽曲別用途メタデータを別資料と照合して採用し、区別と理由を台帳に残した。歌詞本文は転記していない。

公式用途表で対応できた80収録に加え、502収録を曲名・アーティスト別に用途検索した。保留には、用途が見つからなかったものと、原曲/後発カバー、歌入り/インストゥルメンタル、同名別曲、アルバム本編/付属ライブBD等を区別し切れないものが含まれる。曲名やWorkの一致だけから用途を横展開していない。FULL・3Dの同一曲では楽曲としての用途を記載し、アニメ使用音源そのものと同じと主張しない。

「なし」はOverdose・ロキの2曲。Billboard JAPANとJOYSOUND運営会社のノンタイアップ明記を、今回の曲別検索と現行発表に照らして採用。過去の非タイアップ情報だけから、全曲の現在の不存在を推測していない。

## 取得上の制約

公式サイト群の直接取得はHTTP503で、2026-10-21 20時から終了未定のメンテナンス案内だった。公式英語版、ブシロードミュージック、アニメ公式、ヴァンガード公式も同じ応答。閲覧ツールでも503/404となるページがあり、公式ページの検索保存内容、公開プレスリリース、別ドメインの放送局・出版社・主催者資料で照合した。

検索で見つからないだけの曲は「なし」にしていない。そのため確認待ちは416件と多い。これは416曲にタイアップがあるという意味ではなく、使用の有無を確定できないという区分である。人間確認後に根拠とともに更新できるよう列挙した。

最初のsandbox内network取得はEACCES。その後、許可された読取で503を確認。承認拒否・回避・外部書込なし。AWAの公式名義プレイリストも直接閲覧はcache missのため、検索保存の曲表と公式の公開告知、複数のセットリスト資料を照合した。

## 実装と再確認

詳細表示は全種別に欄を1つ表示する。3D/MVと原曲アーティストの条件を保持。管理画面の用途欄を共通入力へ移動し、オリジナル保存時の `null` 強制を解除した。空欄は `null`、確認済み該当なしは文字列 `なし`。ひな型説明も更新した。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/with-node.ps1 node scripts/research/original-work.mjs verify
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/with-node.ps1 node --test tests/research/original-work.test.mjs
```

`report` は一覧の再生成、`apply` は判定済みoriginalWorkの適用。890収録・582対象、対象外308値、非対象フィールドのdigest、同時編集の有無を確認し、不一致時は停止する。人間確認後は判定ルール・台帳・テスト件数も更新する。調査前の `baseline` は再作成しない。

最終検証結果は [validation](validation/) と WORK_LOG.md に記録する。ローカル反映までで、commit・push・本番公開は行っていない。
