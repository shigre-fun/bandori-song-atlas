## 判定範囲と根拠

OP・ED・劇中歌、CM、イベントのテーマ、公式が命名したアーティストタイアップ企画を含む。通常のゲーム収録、一般の実写ライブ演奏、単なるMV公開、作曲者の参加だけでは判定していない。公式にキャラクターソングとして発表されたものは、その用途を記載する。

公式の楽曲別説明、アニメ・映画・放送局の主題歌表、監修された公式曲集、主催者・運営会社の発表を優先。一部は専門誌・楽曲別用途メタデータを別資料と照合して採用し、区別と理由を台帳に残した。歌詞本文は転記していない。

公式用途表で対応できた80収録に加え、502収録を曲名・アーティスト別に用途検索した。保留には、用途が見つからなかったものと、原曲/後発カバー、歌入り/インストゥルメンタル、同名別曲、アルバム本編/付属ライブBD等を区別し切れないものが含まれる。曲名やWorkの一致だけから用途を横展開していない。FULL・3Dの同一曲では楽曲としての用途を記載し、アニメ使用音源そのものと同じと主張しない。
