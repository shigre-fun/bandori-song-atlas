# スマートフォンの一覧・参加クレジット表示

2026-10-22。画像案の確認後、実サイトへの実装・公開を依頼された変更。

ガルパ・アワーノーツの楽曲検索では、スマートフォンのカードを次の構成にする。

- 曲名と右端の「配信日：日付」。アワーノーツだけ曲名の前に既存の楽曲タイプ色の丸を置く。
- 使用作品。値が「なし」または未登録の場合はスマホの行を省く。
- バンドと右端のオリジナル・カバー・エクストラ。
- 5難易度（ガルパ）または4難易度（アワーノーツ）の名称と、その下のレベル。

行間・余白を詰め、BPM・演奏時間はスマホの検索カードから省く。既存の難易度色・楽曲タイプ色・バンド線色・種別ラベルの配色を使う。長い曲名・作品名は1行の省略表示にし、DOMの全文とtitle属性を保持する。デスクトップは従来の表と情報を表示する。

クリエイター一覧は名前と右端の種別、その下に参加楽曲数と担当別曲数を並べる。個人ページも参加クレジットの集計、収録件数、説明を詰める。担当別曲数の間は半角スペース1個で `作詞 264 作曲 0 編曲 0` の形式にする。デスクトップ用の集計・検索並べ替え用データは保持し、整備中・一部登録の状態も0件と区別する。
