# 楽曲データの記入方法

`node scripts/add-song.mjs "楽曲名"` で、このひな型を `data/garupa/songs.json` の新しい曲として追加できます。追加後はIDで曲を探して空欄を埋め、グループの `band` も設定してください。既存グループのバンド・種類と同じ場合は、そのグループに追加されます。
JSONでは文字列を半角の二重引用符で囲み、最後の項目の後にはカンマを付けません。コメントは書けません。

| 項目                        | 記入する内容                                                                                             |
| --------------------------- | -------------------------------------------------------------------------------------------------------- |
| `id`                        | 自動割り当てされる恒久URLの番号。既存曲と重複・再利用不可。`/garupa/songs/{id}/` に使用                  |
| `title`                     | 表示する正式な楽曲名                                                                                     |
| `reading`                   | 50音順用の読み。英語の曲もカタカナで入力                                                                 |
| `category`                  | 追加先グループの種類。`オリジナル`、`カバー`、`エクストラ`。曲の中には保存しない                         |
| `band`                      | 追加先グループの演奏バンド名。曲の中には保存しない                                                       |
| `releaseDate`               | 日本版の配信日時。例：`2026-09-17T15:00:00+09:00`                                                        |
| `releaseOrder`              | 同時配信曲だけ1から順に入力。単独配信は `null`                                                           |
| `composer`                  | 作曲者の表示値。管理画面の直接入力、またはCreator選択から生成                                            |
| `lyricist` / `arranger`     | 作詞・編曲の表示値。未確認は `null`                                                                      |
| `workId`                    | `data/works.json` の固定作品ID。新曲CLIが採番。同作品と確認した既存収録では同じIDを使う                  |
| `credits` / `creditDisplay` | 登録済みCreator ID・担当・表示上書き、および担当別の表示順序。[Creator仕様](../docs/CREATORS.md)参照     |
| `originalArtist`            | 原曲アーティスト。オリジナルや未確認の場合は `null`                                                      |
| `originalWork`              | 原曲が使用されたアニメ・映画等。複数あれば区切って入力。未確認は `null`                                  |
| `live3d`                    | 3Dライブあり：`true`、なし：`false`、未確認：`null`。オリジナルの詳細で表示                              |
| `bpm`                       | 基本BPM。小数可。未確認は `null`。BPM順はこの値を使う                                                    |
| `bpmMin` / `bpmMax`         | BPMの下限・上限。変動時は両方入力し、下限 ≦ 基本 ≦ 上限。一定なら両方 `null` または基本と同値            |
| `durationSeconds`           | ゲーム内の演奏時間を整数秒で記入。秒未満は切り捨てる。例：`105`。フル音源の長さではない。未確認は `null` |
| `aliases`                   | 検索用別名の配列。例：`["作品の略称", "曲名の別表記"]`。不要なら `[]`                                    |
| `relatedSongIds`            | 別譜面・別ゲームの曲ID。例：`["ournotes:7"]`。相手側にも `"garupa:646"` を設定する                       |
| `difficulties`              | EASY・NORMAL・HARD・EXPERT・SPECIALの5項目                                                               |

各難易度は、例のようにレベルとノーツ数を記入します。

作詞・作曲・編曲は管理画面の個別欄へ直接入力できます。直接入力は `creditDisplay` の未同定表記（`unresolved: true`）として保存します。Creatorページへリンクする場合は登録済みCreatorを選択し、担当ごとの順番を設定してください。未登録の主体はCreator管理で追加できます。手編集する場合も `credits` と `creditDisplay` を設定し、表示値と一致させてください。新曲CLIは空のクレジットと新しいWorkを作成します。同一作品の収録を追加する場合は既存Workを明示選択します。タイトル一致だけでは統合しません。

原曲アーティストが複数の場合は、名前を `、` または `/` で区切って入力してください。未同定の既存Creator表記は移行レポートへ記録し旧表示を維持しています。詳細ページでは登録済みCreatorはCreator詳細へ、未同定名・原曲アーティストは従来の横断検索へリンクします。括弧内は名前とまとめて表示し、旧文字列の分割例外は `src/js/credits.js` の `indivisibleNames` で管理します。

```json
"EXPERT": {
  "level": 26,
  "notes": 850
},
"SPECIAL": null
```

未実装の難易度は `null` にします。未確認の譜面数値を仮の値で公開しないよう、ゲームで確認して記入してください。
バンド順に認識される表記は `Poppin'Party`、`Afterglow`、`Pastel＊Palettes`、`Roselia`、`ハロー、ハッピーワールド！`、`Morfonica`、`RAISE A SUILEN`、`MyGO!!!!!`、`Ave Mujica` です。
その他のバンドや複数バンドの合同曲は「その他」に入ります。
